Rozliczenia Warsztatów v4.4
Podmień w głównym katalogu GitHub Pages pliki:
- index.html
- style.css
- app.js

Wersja 4.4 zawiera m.in.:
- czerwony przycisk Usuń zajęcia z potwierdzeniem,
- status BRAK WPŁATY bez czerwonej chmury,
- wyszukiwarkę dzieci przy wpłatach,
- ręczne dodawanie i korektę danych,
- rabaty i status BEZPŁATNE,
- dodatkowe przychody,
- filtr grup: szkoła + dzień + godzina,
- drukowanie wyselekcjonowanej listy,
- ekran importu wpłat ze screena z etapem ręcznej weryfikacji,
- numer wersji 4.4 widoczny w nagłówku.

UWAGA: sama statyczna strona GitHub Pages nie może bezpiecznie wykonywać OCR bankowego screena po stronie serwera. W tej wersji plik screena jest wybierany lokalnie, a zapis wpłaty wymaga weryfikacji.
