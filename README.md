# Rozliczenia Warsztatów — prototyp

Wersja demonstracyjna pod GitHub Pages.

**Nie wpisuj prawdziwych danych dzieci ani rodziców.** Dane są zapisane tylko lokalnie w przeglądarce (localStorage).

Pliki do wgrania do repozytorium:
- index.html
- style.css
- app.js

Po wgraniu włącz GitHub Pages w Settings → Pages → Deploy from a branch.
